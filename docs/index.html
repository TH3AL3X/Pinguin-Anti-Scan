04 / READ BEFORE DEPLOYING PENGUIN

Questions worth asking.

01 Can it fix my Wi-Fi ping spikes?

It may help when those spikes come from periodic WLAN scans or roaming behavior. It cannot fix congestion, interference, weak signal, router issues or bufferbloat.

02 Why does it need administrator access?

Windows restricts changes to wireless interface settings. The app asks for elevation when it starts so it can request that change.

03 How do I know it is working?

The “Penguin on guard” state appears only after Windows reports that background scanning is disabled for the selected adapter.

04 How do I restore normal scanning?

Choose “Exit and restore Wi-Fi” from the tray menu. The app restores the normal background-scan behavior before it quits.
